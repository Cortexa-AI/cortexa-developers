## Access and authentication

<AccordionGroup>
  <Accordion title="How do I get sandbox access?">
    Contact your Cortexa integration representative for application credentials,
    a test clinician and workspace, and the Cortexa app URL. See [Sandbox](/sandbox).
  </Accordion>
  <Accordion title="Can I call clinical endpoints with an API key?">
    Exchange the API key and a clinician authorization code for a Partner JWT.
    Use that JWT for clinical requests. A normal Cortexa login token cannot
    replace it. See [Authentication](/authentication).
  </Accordion>
  <Accordion title="What is external_user_id?">
    The clinician's user ID in your system. Your application includes it in the
    authorization link. It is required; reuse the same ID when they reconnect.
  </Accordion>
  <Accordion title="Does the clinician sign in for every API call?">
    No. After the first authorization, your backend can renew tokens with its
    API key and the saved grant ID. Reconnect only when authorization is no longer valid.
  </Accordion>
  <Accordion title="Can one application serve multiple clinicians?">
    Yes. Save each clinician's grant for their selected workspace. Patients and
    sessions are scoped to the grant that created them.
  </Accordion>
  <Accordion title="How does a clinician change the connected workspace?">
    Send them through authorization again to select the workspace. Use the returned
    grant for subsequent requests; changing workspaces in Cortexa does not change an existing grant.
  </Accordion>
</AccordionGroup>

## Building your workflow

<AccordionGroup>
  <Accordion title="Do I need audio to try note generation?">
    No. The [Quickstart](/quickstart) uses a short synthetic transcript.
  </Accordion>
  <Accordion title="Can I transcribe during a consultation?">
    Yes. Send [independent audio chunks over HTTP](/segmented-transcription).
    Each returns text; finish the recording to assemble the session transcript.
    This is not a WebSocket audio stream.
  </Accordion>
  <Accordion title="Do I need to poll for notes?">
    Consult notes and document content [stream by default](/streaming), including
    the saved result. For background processing, set `stream=false` and
    [poll the returned jobs](/jobs). A `202` receipt does not contain the finished note.
  </Accordion>
  <Accordion title="Is there a ready-made interface?">
    Embed the [Widget](/widget) for recording, generation, and review. Use the
    [JavaScript SDK](/javascript-sdk) or HTTP API to build your own interface.
  </Accordion>
  <Accordion title="How do I save the note to my EHR?">
    Write the reviewed result through your EHR API or an [approved connector](/connectors).
    Use [section mappings](/sectional-notes) for separate EHR fields. Editing a
    Cortexa document saves it in Cortexa.
  </Accordion>
  <Accordion title="Can I generate a custom format?">
    Use [custom prompts](/custom-templates) for free-text documents, or
    [structured forms](/structured-responses) for typed questions, options,
    dates, and repeated entries. Arbitrary JSON Schema is not supported.
  </Accordion>
  <Accordion title="Which languages, regions, and code systems are available?">
    Confirm these with Cortexa for your environment. Clinical codes are
    suggestions for review; [E/M assessment](/clinical-coding) covers US outpatient MDM.
  </Accordion>
</AccordionGroup>

## Troubleshooting

<AccordionGroup>
  <Accordion title="Why does an existing session return 404?">
    Check the session ID and grant. Sessions from another grant, including
    unshared internal Cortexa sessions, are not automatically accessible.
  </Accordion>
  <Accordion title="How do I retry without creating duplicates?">
    Keep the same request body and idempotency key. Patient and session creation
    use external IDs; audio chunks use the recording ID and index. See [Errors](/errors).
  </Accordion>
  <Accordion title="Does changing context update existing notes?">
    Context changes apply to future generation. Edit or regenerate an existing
    document to update its text.
  </Accordion>
  <Accordion title="What should I send to support?">
    Send the operation, HTTP status, failure code, and `X-Cortexa-Request-Id` to
    your integration contact. Exclude credentials and clinical payloads.
  </Accordion>
</AccordionGroup>

## Get started

1. [Get sandbox access](/sandbox) for your application and test clinician.
2. [Connect the clinician](/authentication) and obtain an access token.
3. [Generate your first note](/quickstart) from a short synthetic transcript.

Sandbox API base:

```text
https://sandbox.api.cortexanote.com/v2/scribe/open-api
```

## Core concepts

| Term | Description |
| --- | --- |
| Partner application | Your integration, identified by its application ID and server-side API key |
| Grant | A clinician's authorization for your application to use one workspace |
| Patient | A patient record belonging to the grant |
| Session | One consultation, with its transcript, context, and outputs |
| Template | Instructions and structure for generating an output |
| Document | A note, letter, or other generated or edited output |
| Job | Background work whose status you can query |

Patients and sessions are scoped to their grant. See
[How an integration works](/integration-flow) for the complete consultation flow.

Use the sandbox to build and test your integration with synthetic patients,
recordings, and notes. Contact your Cortexa integration representative for access.

## What you need

| Item | Purpose |
| --- | --- |
| Application ID and API key | Identify your integration and obtain access tokens |
| Registered HTTPS callback | Receive the clinician's authorization code |
| Test clinician and workspace | Sign in to Cortexa and authorize your application |
| Cortexa app URL | Open the clinician sign-in and consent page |
| Scopes, templates, and entitlements | Enable the workflows you plan to test |

Tell your contact which workflows you need, including audio, attachments, custom
templates, or coding.

A **sandbox clinician account** is a test Cortexa account used to authorize your
application. Your backend then exchanges its API key and that authorization for
a Partner JWT. The JWT is what you use to call clinical endpoints.

## API address

```text
https://sandbox.api.cortexanote.com/v2/scribe/open-api
```

This address serves the API. Use the separate Cortexa app URL supplied during
onboarding for clinician sign-in and consent.

You can retrieve the public API specification without credentials:

```bash
curl --fail-with-body \
  'https://sandbox.api.cortexanote.com/v2/scribe/open-api/openapi.json'
```

## Make your first authenticated request

Complete [Authentication](/authentication) and set `CORTEXA_JWT` to the returned
access token. Then read the authorized workspace:

```bash
export CORTEXA_API_BASE='https://sandbox.api.cortexanote.com/v2/scribe/open-api'

curl --fail-with-body "$CORTEXA_API_BASE/teams" \
  --header "Authorization: Bearer $CORTEXA_JWT"
```

Next, [generate your first note](/quickstart). Add the audio and context workflows
your product needs after the text example works.

## Move to production

Arrange a production application, credentials, callback, and API address with
Cortexa. Sandbox grants and resource IDs are specific to the sandbox environment.
See [production preparation](/production) for the handoff.
